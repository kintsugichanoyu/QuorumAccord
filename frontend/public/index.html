01 / The protocol

From observation
to agreement.

A small set of building blocks, with a clear job for each. Workers do the measuring. The program enforces the rules.

01

Observe

Each Rust producer reads one account metric, converts it to a fixed-point integer, and submits its sample.

The driver contract ↗
02

Reach consensus

Registered operators vote within slot windows. Once quorum and publication conditions are met, a finalized value enters the feed.

The on-chain contract ↗
03

Build on the result

Consumers read published feeds, apply an integer risk rubric, and submit allocation weights for a second round of consensus.

Allocation consumers ↗

↳ Quorum publishes data and weights. A separate application decides how to act on them.

02 / Made for builders

A focused worker.
A bigger network.

Start with one metric. Give each operator its own signer and deploy one producer per feed. The Rust workspace handles instruction encoding, RPC reads, signing, and retries.

QUORUM / PRODUCER

# After configuring your signer, feed, and source

export DRIVER=offset_u64
export POOL_ID=1 DATA_ID=0
export OFFSET=8 SCALE_NUM=1 SCALE_DEN=1

# Start the Rust producer
cargo run --release --locked \
  --manifest-path workers/Cargo.toml \
  --bin quorum-producer

# After configuring APY / CRR feeds and an open round

export ROUND=0
export STALENESS_SLOTS=150000

# Start the Rust allocation consumer
cargo run --release --locked \
  --manifest-path workers/Cargo.toml \
  --bin quorum-consumer
